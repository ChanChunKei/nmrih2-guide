## Report an issue or correction

Use the public GitHub issue tracker to report broken links, outdated version references, factual errors, or sources that should be reviewed.

### Include enough context to verify it

Please include the guide URL, the specific claim, the game version or date you tested, and a direct primary source or independent community source when available.

[Open a NMRiH2 Guide issue](https://github.com/ChanChunKei/nmrih2-guide/issues/new)

## What we can review

We prioritize reproducible corrections, official patch changes, and community observations that can be independently checked. A submitted issue does not guarantee publication, especially for claims about fixed loot, unverified map routes, or “best” strategies.
