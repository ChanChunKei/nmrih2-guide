Skills are a long-term choice, so a good rule is simple: select for the way your squad survives, not for a hypothetical perfect build.

## Choose a clear purpose

Prioritize a skill when it consistently improves one of these jobs: keeping the team supplied, handling pressure safely, reaching objectives, or recovering from mistakes. A smaller benefit that helps every run is often more useful than a situational pick.

## Current 1.0 skill pool

Armageddon 1.0 added Handgun Reloading, Rifle Reloading, and Shotgun Reloading. It also removed Averaging, Guts, and Teddy Bear. Build recommendations written before August 2026 may therefore describe a different skill pool.

<div class="guide-callout"><strong>Live-game rule:</strong> Use the current in-game skill screen as the source of truth for names, requirements, and effects. [Official 1.0 notes](https://www.nmrih2.com/2026/08/10/armageddon-1-0-update-notes/)</div>

## Pair skills with the team

Tell the squad what your selection enables. The value of a skill grows when teammates know when to rely on it and when to protect the player using it.
