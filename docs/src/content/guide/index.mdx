## Play with a plan

The safest run is rarely the one with the most kills. Keep your group together, call out what you find, and make every detour answer a simple question: does it improve the team’s chance of extracting?

Use the guides in this order if you are new: [Beginner Guide](/beginner-guide/) → [Weapons](/weapons/) → [Maps](/maps/) → the map you are deploying into.

## Guide standards

- Game facts are reviewed against official release notes as each page is expanded.
- Each page identifies the release context it covers, so obsolete pre-1.0 guidance is not presented as current.
- Advice is labeled as guidance, so you can adapt it to your squad and difficulty.
