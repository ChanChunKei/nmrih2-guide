### Crossplay answers the platform question, not every account question

Crossplay means supported platforms can play together. The official announcements used here do not document cross-progression, account linking, invite-button labels, or every platform-specific restriction. Treat those details as unconfirmed until Torn Banner publishes a current support note.

## Prepare a mixed-platform squad

1. Confirm that everyone is using a supported storefront and has installed the current game update.
2. Agree on the host and party plan before deploying, then use the game’s current social or invite flow rather than relying on an old screenshot or menu label.
3. Start a first session with the same communication and regroup plan you would use for any squad; crossplay does not remove the need to call objectives, supplies, or extraction.
4. If a feature behaves differently after an update, check Torn Banner’s current news or support channels before assuming the platform is unsupported.
