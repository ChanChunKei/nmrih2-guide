## An independent fan guide

NMRiH2 Guide is an independent fan resource for **No More Room in Hell 2**. It is written and reviewed by the NMRiH2 Guide Editorial Team and is not affiliated with, endorsed by, or sponsored by Torn Banner Studios, Lever Games, Valve, or Steam.

## How we review information

### Officially confirmed

Game rules, supported platforms, patch changes, and current game descriptions are checked against official announcements, patch notes, or in-game descriptions whenever they are available.

### Community-tested

Player tactics may be included only when two independent, public, recent sources support the same reproducible conclusion. These sections are labeled **Community-tested** and remain separate from official rules.

### Community-reported

One-source player observations can appear only as clearly labeled items awaiting independent confirmation. They are not presented as recommendations, fixed routes, or best-in-slot advice.

## Version and correction policy

Every guide is written for a stated release context and is reviewed after relevant official patches. When an older claim cannot be confirmed for the current version, we revise, qualify, or remove it instead of keeping it as general advice.

Found an error, an outdated source, or a reproducible tactic worth reviewing? [Open a GitHub issue](https://github.com/ChanChunKei/nmrih2-guide/issues/new).
